# Quiz-Application
A simple and interactive HTML &amp; CSS Quiz built with HTML5 and CSS3, featuring 10 multiple-choice questions, interactive answer selection, hover effects, and visual feedback for correct and incorrect answers.

## Project Overview

This project contains **10 multiple-choice questions** based on essential HTML and CSS concepts.

The interface is designed with a clean layout where users can select an answer and instantly see whether their selected option is **correct or incorrect** through visual feedback.

The project focuses mainly on practicing HTML structure and CSS styling without using JavaScript.

## Features

- 10 HTML & CSS multiple-choice questions
- Radio button based answer selection
- Correct and incorrect answer styling
- Interactive hover effects
- Clean and simple user interface
- Organized question and option layout
- Responsive-friendly structure

##  Built With
